## Use the notes with the code

1. Read the core rule and worked example.
2. Predict the result before reading the expected output.
3. Open the matching source file in RustRover and run its `main` function.
4. Change one detail and explain any change in output or compiler diagnostics.
5. Record your own mistake and correction below the relevant note.

The notes provide reference explanations; the `.rs` files remain the runnable examples and your practice workspace. Your source files may contain additional experiments, so their latest output can differ from a short example shown in a note.

## Use another computer

Clone or pull the repository, then open its `vault` folder as an Obsidian vault. Internal note links use Obsidian wikilinks. Code links open GitHub; local source locations are written relative to the repository root, without a fixed drive letter or user directory. Sign in to GitHub if the repository requires it.

Run the Cargo commands from the repository root, where `Cargo.toml` lives, rather than from the vault folder. Obsidian's local settings and workspace state stay on each device; no community plugin is required to read these notes.
