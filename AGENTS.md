# RustLab learning rules

- Write all new Rust comments, exercise prompts, and identifiers in English.
- Explain lessons in Chinese outside source code when requested.
- Preserve the learner's implementations. Do not fill in exercise solutions.
- Teach Lecture 5 in small steps; distinguish announced quiz topics from supplements.
- Give only one to three review questions per knowledge block, at least as challenging as the reviewed Quiz 1 and Quiz 2 questions.
- Focus on quiz review until the learner asks to switch to an assignment or project.
- For each new lesson, provide previously learned type definitions and routine main setup/printing; leave the current topic implementation and impl blocks for the learner.
